# ADR-022：Agent Skills 指令包

> 状态：已实施（首版）
> 日期：2026-10-02
> 范围：技能包存储、导入、渐进披露运行时、System Prompt 与设置界面

## 背景

代码中的 `SkillDefinition` / `SkillRegistry` 实为函数调用工具。旧“自定义 Skill”保存名称、描述与代码，但没有隔离执行器，从未广告给模型。用户需要的是可复用、可分享的任务指令：在合适的任务中让模型按既定流程、规范与参考资料工作，而不是新增可执行代码。

## 决策

1. 采用开放的 Agent Skills 目录格式：每个技能是一个目录，根部 `SKILL.md` 以 YAML frontmatter 声明 `name`（小写字母、数字与连字符，≤64）与 `description`（≤1024），可选 `license`、`allowed-tools`；正文为 Markdown 指令；同目录可附带参考文件。
2. 技能包保存在应用私有目录 `files/agent_skills/<name>/`，不新增 Room schema。全局启用集合保存在 `nexara_settings` 的 `agent_skills_enabled`，并纳入偏好备份；新安装的技能默认启用。
3. 导入支持 `.zip` 与单个 `SKILL.md`。ZIP 只接受相对路径，拒绝绝对路径、`..`、符号链接语义与保留名；限制总解压 5 MiB、单文件 1 MiB、最多 200 个文件；`SKILL.md` 必须位于根部或唯一顶层目录下。同名技能需显式覆盖。
4. 渐进披露：System Prompt 只列出已启用技能的名称与描述（最多 50 个、4000 字符）；模型通过内置只读工具 `activate_skill(name)` 获取正文与文件清单，通过 `read_skill_file(name, path)` 读取附带文本文件（单次 256 KiB）。没有启用的技能时两个工具都不广告。
5. 技能内容是用户安装的指令，按用户授权的提示词对待；工具结果标注来源。技能不能改变工具集合、审批模式或执行脚本：`allowed-tools` 仅解析与展示，首版不执行收窄；附带脚本只可读取，不执行。
6. 旧自定义工具定义保留在数据库中，设置页单独列为“不会执行”的旧版定义，可查看与删除；不自动迁移或删除用户数据。

## 结果与边界

- 不新增数据库迁移；技能目录不进入加密备份包，换机需重新导入（后续工作）。
- `allowed-tools` 收窄、按 Agent 绑定技能、技能脚本执行属于后续工作，需另行设计隔离与审批。
- 技能正文进入模型上下文，过长正文会消耗上下文预算，由工具结果预算与上下文压缩共同约束。

## 验证

- JVM：frontmatter 解析与校验、ZIP 路径与容量门禁、存储增删改与启用状态、工具可用性与读取边界、System Prompt 技能段落。
- 设置界面以截图基线覆盖技能包列表。
