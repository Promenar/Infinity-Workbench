## 证据规则

每个 PASS 绑定确切源码身份、命令、工具链和报告；设备证据另绑定 API/ABI/序列号，交付证据另绑定 APK SHA-256。工作树行为修复经过 RED/GREEN 后才能关闭缺陷；源库快照保留不等于附件/历史记录已经可用。单次网关兼容测试不外推厂商原生协议、视觉能力、Embedding 或 Rerank。

工作区创建恢复依赖应用私有操作目录与根锁的独占约束。公开目标先进入隔离区再核验持续身份，发布使用不可覆盖的原子移动；清理只删除已核验的直属节点和空目录。该保证不涵盖同 UID 代码绕过根锁，在核验与 unlink 之间篡改私有操作目录。
