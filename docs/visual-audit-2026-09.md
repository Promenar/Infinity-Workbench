## 三、修复优先级建议

1. **P0-1/2**：RichContentWebView/ECharts/Mermaid 管道 charset 配置（疑似 WebView 加载未声明 UTF-8 或内容被按 Latin-1 解码）——一处修复惠及两类图表。
2. **P0-3**：LaTeX 渲染器支持单 `$` 行内定界（InlineLatexSpan 已存在，接匹配规则）。
3. **P0-4**：排查 image_generation 注入条件（`ToolOrchestrationPlugin`/`ContextBuilder`），确认工具注册与会话建立的时序耦合。
4. **P1-5/6/7**：富文本悬浮按钮层级落点；代码块行号框与高亮框对齐；代码 token 配色提亮括号色。
5. **P1-9**：代码块工具按钮与色板补足 48dp 触控（L2 有完整坐标清单）。
6. **P2**：token 治理专项——先决策是否把 4/10/20/40dp 纳入标尺，再批量清理 1519 处字面量；其余逐条打磨。
7. **功能疑点**：会话删除失败（`SessionDeletionUiAction` 为薄封装，根因在领域层删除事务，建议查 `SessionRepository` 删除路径对失败生成态的处理）。
