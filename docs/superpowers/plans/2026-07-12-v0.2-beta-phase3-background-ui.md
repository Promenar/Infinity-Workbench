# Nexara v0.2-beta Phase 3 Background and UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让前台发起的生成在后台、锁屏、旋转和 Activity 重建后可靠继续，并完成首次引导、双语、自适应、无障碍与视觉回归。

**Architecture:** 应用级 `GenerationCoordinator` 成为唯一任务所有者，Foreground Service 只观察同一状态并承载通知；UI 拆 Route/Content；Onboarding 使用可恢复状态机；全站用统一自适应容器和资源化文案。

**Tech Stack:** Coroutines/StateFlow、Foreground Service `dataSync`、Compose Navigation、AppCompat locale API、Compose UI Test、UiAutomator、Gradle Managed Devices、Compose Screenshot Testing。

## Global Constraints

- 全局最多一个生成任务，每 Session 最多一个；重复请求返回 Existing，不发第二个网络请求。
- `onCleared()` 不取消生成；终态必须 flush 消息、取消底层 Flow 并停止服务。
- 通知包含返回会话与停止；陈旧 taskId 不得取消新任务。
- 首次引导固定为语言、Provider、连接、模型、Agent、首聊，首聊完成后才标记 COMPLETED。
- `<600dp` Bottom Navigation，`>=600dp` NavigationRail，正文最大宽度 `960dp`。
- 所有操作目标至少 48dp；动态状态通过 live region/状态描述公开。
