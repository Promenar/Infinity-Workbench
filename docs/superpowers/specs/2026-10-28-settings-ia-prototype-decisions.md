# 设置信息架构原型：界面决定

- 状态：已确认（2026-10-28）
- 原型：[Nexara 设置信息架构原型](https://claude.ai/artifact/WbqNMZtxPaQRkXCXX1YD9v)（私有 Artifact，含全局设置、智能体编辑页、会话设置面板与知识检索界面）
- 依据：`docs/superpowers/specs/2026-10-28-settings-ia-audit.md` 第 4 节目标结构；`docs/superpowers/specs/2026-10-28-agent-knowledge-search-tools.md`
- 用途：W2-F、W3-F 的界面依据。编号 H 首页、K 知识库设置、G 智能体编辑页、A 调试与高级、S 会话设置面板、C 对话页知识检索、R 可达范围与外部文件夹、T 智能体运行。括号中的 P、L、D、M、T 编号指审计文档的问题编号。

## 1. 设置首页

- H1 分组顺序：用户资料、通用、模型、智能体运行、知识库、执行环境与连接、数据、关于。
- H2 “知识库”分组四行：知识库设置（新会话默认、检索、模型、每轮抽取同在一页）、知识图谱、长期记忆、调试与高级。
- H3 “智能体运行”四行：执行轮次与预算、内置工具、技能包、MCP 服务器；“执行轮次与预算”页名不变。
- H4 “执行环境与连接”七项直接列在首页，不设二级分组页；顺序为 Linux 环境、Termux、SSH 主机、Tailscale、网络访问、Git 凭据、后台与定时，副标题显示状态。
- H5 Linux 新会话默认模式只保留在 Linux 管理页“会话”分组；安装流程中的选择改为安装完成后在此修改。

## 2. 知识库设置

- K1 检索深度用三段分段控件“精简 / 均衡 / 全面”，点选即套用、不弹确认；原始值不匹配任何档位时追加第四段“自定义”，显示为选中且不可点。控件下方一行显示四个原始值。
- K2 “新会话默认”放在页首，四个开关与会话面板同名：对话记忆、资料检索、重排序、知识图谱；未设置重排模型时“重排序”置灰并写明原因。全文统一用“重排序”。
- K3 模型分区：嵌入、重排两行点按跳转“默认模型”页；图谱抽取、查询改写两行就地弹出选择，未单独设置时显示“跟随快速模型”。图谱抽取现已按“快速模型 → 主模型”回退；查询改写现直接回退主模型，由 W2-B 改为与图谱抽取相同的回退顺序。
- K4 查询改写关闭时置灰查询改写模型；混合搜索关闭时置灰混合权重与关键词权重；改写策略不是多查询时置灰变体数。
- K5 “每轮抽取”两项说明统一为“每轮额外调用一次模型”；页脚说明“提取事件与状态”需开启对话记忆。
- G1 图谱抽取模型在知识图谱页与知识库设置 › 模型两处可改，指向同一个设置。

## 3. 调试与高级

- A1 高级参数为一个可展开行，展开后分七组：分块、检索数量、相似度阈值、混合搜索、查询改写、图谱检索、图谱抽取；不记住展开状态。
- A2 分块大小、重叠、记忆分块大小任一项与已建索引的值不同时，页顶显示警示条与“全部重新向量化”按钮；改回原值后提示消失。
- A3 数值编辑统一用底部面板：大号数值、加减按钮、常用值标签、恢复默认，沿用 `NexaraValuePickerSheet` 的形式。
- A4 “全部重新向量化”同时放在索引数据分组，不改分块也能手动重建。

## 4. 智能体编辑页

- G2 “基本信息与外观”一组：名称、描述、图标、颜色四行，头像仍在页顶，颜色用色点就地选择。
- G3 采样参数折叠为一行；面板内先选参数方案再看数值，参数方案的选择、保存与删除都在面板内，页脚写明方案全局共享；改数值即脱离方案。
- G4 新会话默认：执行模式、默认工作区用单选面板，默认工作区可选“不设默认”；MCP 用开关列表面板，只列全局已启用的服务器。技能为只读摘要“用户技能 N 个已启用”，点按跳转全局技能包：运行时尚未读取智能体与会话的技能名单，逐项开关留待运行时支持后再开放（后续项）。
- G5 检索方式、知识库文件访问用“值行 + 单选面板”，每个选项带一句影响说明（首字速度、工具调用、授权）；两项互不联动，“每轮自动”时文件访问仍可设置。
- G6 私密智能体放在“知识与记忆”分组；检索范围三行单独成组；私密说明补充“其他智能体选择全部智能体时也读不到”（T9）。
- G7 删除确认写明会话数：“将先关闭 N 个会话，再删除智能体”，与首页删除一致（D3）。

## 5. 会话设置面板

- S1 “关闭工具时保留联网搜索”是“启用工具”下的缩进子项，工具开启时也可预先设置；模型不支持工具调用时整行隐藏。
- S2 工具关闭时置灰执行模式、技能、MCP，分组页脚说明当前只保留 Web 搜索或不调用任何工具。
- S3 技能只读摘要为一行“用户技能 N 个已启用”，副标题写项目技能数与工作区，点按跳转全局技能包。
- S4 会话选项只剩“告诉模型当前时间”，仍保留分组标题。
- S5 文档范围第二档“工作区与资料”改名“工作区与知识库”，说明改为“另含知识库中的文档”。底部“资料”页签保留原名：它同时承载文件、知识库与导入。
- S6 消息字号留在“显示”分组，副标题“只影响本会话的消息正文”，页脚指向外观里的整体文字大小。
- S7 检索范围页脚“智能体设置”可点，跳智能体编辑页；超出上限的档位在选择面板中置灰并提示去调高。
- S8 采样参数用中文主名（温度、话题新鲜度、词频惩罚），英文参数名作副标题。

## 6. 对话页知识检索

- C1 工具步骤行文案为“检索了知识库 · N 条结果”，替换现有“检索了资料”。
- C2 检索详情页签上方写“智能体检索 · 查询词：…”，条目左上角显示引用编号 K1…，分数行为“相似度 · 重排分”。
- C3 审批卡类别条“内置工具 · 访问授权”，标题“需要批准：读取知识库”；正文依次为申请原因（引用样式）、知识库名称与文档数、挂载路径、只读说明；批准后卡片按现有审批流程收起，下方接读取步骤。
- C4 审批卡仅在知识库文件访问为“按需申请”且会话工具开启时出现。
- C5 文档条目的读取路径行：已挂载显示 `/mnt` 路径；未挂载显示“知识库未挂载”；其他会话工作区显示“只提供片段”；历史对话条目没有路径行。

## 7. 可达范围与外部文件夹

- R1 “知识库 · 只读”为信息色小标签带锁图标，与“系统授权”“仅文件工具”等中性标签同排；可达范围路径区用同一标签。
- R2 外部文件夹面板增加“挂载知识库”行（批准后置灰）；移除挂载走确认框。
- R3 可达范围的网络项改为跳转：“局域网与本机白名单”一行显示全局项数与“去修改”，点按关闭面板并打开全局网络访问页（L2）。
- R4 面板标题为“智能体可达范围”。

## 8. 智能体运行

- T1 内置工具页列出 `knowledge_search`，副标题说明由检索方式决定是否提供；是否需要全局开关由 W3-F 按设计稿决定，默认不加。
- T2 Web 搜索域名过滤两个列表：“只搜索这些域名”“排除这些域名”，每行一个域名，对话框编辑。

## 9. 需补的通用组件与数据

| 缺口 | 现状 | 归属 |
| --- | --- | --- |
| 分段控件不可点段（K1） | `NexaraSegmentedControl` 每段都可点 | W2-F |
| 设置行式折叠区（A1） | `NexaraCollapsibleSection` 是无底色小标题折叠，不在 `NexaraSettingsGroup` 内 | W2-F |
| 技能只读摘要（S3） | 会话工具页用 `SessionSkillsSections` 渲染完整列表与开关 | W2-F |
| 默认工作区改为一行（G4） | `AgentDefaultWorkspaceSection` 是独立分区 | W3-F |
| 访问授权审批卡（C3） | `ApprovalKindBand` 只区分命令后端与内置工具；`ApprovalCallBody` 无原因、知识库、只读说明 | W3-F（数据契约由 W2-B 提供） |
| 检索详情引用编号与路径（C2、C5） | `RagDetailsSheet` 条目无编号、路径、查询词 | W3-F（数据由 W2-B 提供） |
| 只读挂载标签（R1） | 挂载标签只有授权方式与工具范围两类，`ExternalMount` 无 `readOnly` | W3-F（字段由 W2-B 提供） |
| 查询改写模型回退（K3） | 直接回退主模型 | W2-B |
| 图谱抽取预算默认值 | 原型为示意值 | W2-F 按代码现值显示 |

文案方面，`memory_scope_agent`、`agent_memory_private`、`params_source_agent`、`ltm_enabled` 等字符串仍写“助手”；“以 &brand; 身份”除审计文档 T2 点名处外，还见于 `agent_reach_backend_builtin_scope`、`chat_approval_kind_builtin_command_detail`。均由 W3-F 统一处理。
