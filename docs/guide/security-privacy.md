# 密钥与隐私

> 所属：[使用指南](README.md)。仓库首页只介绍概览，本文给出完整说明与边界。

- API Key、Vertex 凭据、搜索 Key、WebDAV 凭据、SSH 认证材料及本机 MCP 令牌由 Android Keystore 支撑的 `SecretStore` 管理，不以明文写入普通配置。
- 密钥字段默认显示 `****`；用户可在当前页面临时显示完整值，离开页面或失去焦点后重新隐藏。
- 备份默认排除所有 Key。启用“包含完整密钥”时必须设置备份密码；备份包使用 PBKDF2-HMAC-SHA256 派生密钥和 AES-256-GCM 加密。
- 智能体与用户的照片头像随备份迁移（备份包格式 3 的 `avatars/` 分区，包内只存随机 ID 引用，不带源设备路径；单张 2 MiB、合计 8 MiB 以内，超限或缺失的照片跳过并清空引用）。旧版本应用会拒绝格式 3 的备份包；格式 1、2 的旧包仍可导入，但不含照片。
- SSH 主机配置、信任记录和全部 SSH 凭据均不进入应用备份，包括启用“包含完整密钥”的加密备份；换设备需要重新配置与确认指纹。SSH 私钥、密码和口令不会交给模型，底层 SSH 日志关闭，工具错误只返回稳定错误代码，远端文本按当前连接的认证材料脱敏。
- Git 凭据（主机、用户名与访问令牌）不进入应用备份，包括启用“包含完整密钥”的加密备份；令牌只由 App 内凭据注入代理使用，不出现在命令、环境变量、文件、输出或模型上下文中。
- Linux 模式的 `gh` 拿到的 `GH_TOKEN` 是本条命令的一次性凭证，不是 GitHub 令牌；应用只向 GitHub API 与上传主机注入真实令牌，下载主机不带认证，其它主机一律拒绝，命令结束后凭证吊销、连接关闭。应用不改写用户自己的 gh 配置。
- 保密输入卡与输出卡：AI 用 `request_secret` 请求保密值时，值由应用直接写入所选去向，AI 只收到状态；输入卡与正在显示原文的输出卡所在窗口禁止截屏录屏，输入框不进入输入法学习。会话保密库只在内存中，会话删除、应用退出即清除，不进入备份；输入回执与输出卡只从会话记录里的工具参数和结果恢复，值销毁、随应用重启清除或被同名新值替换后，输出卡收成一行记录，不能再显示或复制；保密值不进入消息、工具账本、日志与诊断导出，命令输出（含后台任务日志与 SSH 输出）中的原文及其 Base64、URL-safe Base64、百分号与十六进制编码在写盘与显示前遮蔽。写入 Git 凭据、SSH 主机或服务商密钥后，值遵循该去向既有的存储与备份策略，与在设置里直接填写相同。`session_env` 环境变量能被命令读取，只靠输出遮蔽做逻辑隔离，能写入凭据去向时优先使用凭据去向。Termux 后端自身写出的原始日志与命令主动写入文件的内容不在遮蔽范围内。
- Termux 集成、本机 HTTP MCP 的启用开关和本机 MCP 令牌属于当前设备的授权，不随应用备份迁移；另一台设备需要单独配置与启用。
- 内置 Tailscale 的节点状态写入不进备份的应用私有目录，auth key 存于 `SecretStore`；两者不进入备份、日志、命令行与模型上下文，换设备需要重新登录。本机代理只监听 `127.0.0.1` 并只接受每次启动随机生成的凭据；该凭据经代理环境变量交给 `shell_exec`/`python_exec` 子进程，命令可读取，Infinity Workbench 退出后失效。
- 云端 Provider、WebDAV 与远端 MCP 使用 HTTPS；网络安全配置仅对精确地址 `127.0.0.1` 放开明文。本机 MCP 需显式启用和 Bearer 认证，因为同机其它应用也可能访问该端口；`localhost`、其它 IPv4 和 IPv6 地址均不作为 HTTP 例外。
- Release 诊断事件不得写入 Prompt、模型输出、请求/响应正文、完整 URL、Authorization、API Key、SQL 参数或完整异常堆栈；文件限制为 512 KiB，并可由用户主动导出。
