# 工作区与外部文件夹

> 所属：[使用指南](README.md)。仓库首页只介绍概览，本文给出完整说明与边界。

## 自选工作区使用

工作区分三类：**会话专用空间**（默认，带文件版本与回收站，计入备份，随会话删除）、**内置文件系统**（应用私有目录下的文件夹，两个渠道都可用，跨会话共用，不进备份、卸载即删除）、**设备文件系统**（侧载版的共享存储文件夹，需授予所有文件访问，卸载后保留，可与文件管理器、Termux 或电脑同步）。后两类合称目录工作区。在 Agent 编辑页设置“默认工作区”，之后新建的会话会继承它；也可以点会话标题下方状态行中的工作区，在“Agent 可达范围”面板的工作区一节点“切换”，在按三类分组的选择器中为单个会话切换或改回会话专用空间（生成中或有待审批时不可切换）。资源管理器只负责浏览文件，工作区不可用时在文件页说明原因。浏览时跳过符号链接与 `Android/`。

切换后，文件工具的 `/` 指向所选目录，`/mnt/<别名>` 挂载照常可用；命令直接在该目录运行，不做改动对账，可用 `git status` 查看改动。聊天中会留下一条切换提示（不发给模型），模型从系统提示词得知当前工作区。目录缺失或授权失效时工具一律拒绝执行，不会改用会话专用空间；会话设置中会显示原因。生成进行中或有待审批调用时不能切换。删除会话、删除 Agent 或把工作区移出列表都不会改动目录中的文件。删除使用会话专用空间且其中有文件的会话时，默认把文件保留到内置文件系统的 `session-年月日-时分` 文件夹并以会话标题登记，也可选择一并删除。

会话专用空间计入备份上限，不适合存放 git 仓库；在会话专用空间执行 `git clone` 会提示改用目录工作区。共享存储大小写不敏感且不支持符号链接，内置 git 会自动写入兼容配置并说明受影响的路径。工作区是 git 仓库时，会话顶栏标题下方和资源面板显示分支、改动数与相对上游的领先/落后提交数，点开 Git 面板可查看跟踪的上游、HEAD 与上次抓取时间，以及已暂存、未暂存、未跟踪文件（含增删行数）、最近提交与本地分支；面板只读，标题为仓库名（远端的“所有者/仓库”，没有远端时为目录名）；提交与推送直接告诉 Agent，由它执行并在运行命令前请你批准。资料页“浏览”分组中的“工作区”可只读浏览已登记目录，并把单个文件加入资料。

会话资源面板的文件区跟随当前工作区：目录工作区下直接列出该目录内容，可逐级浏览、预览文本文件或用其它应用打开只读副本；与文件工具一样跳过符号链接和 `.infinity/` 内部目录。应用内部数据（回收站、版本历史、命令标记、后台任务日志）存放在应用私有存储；必须与文件同卷的暂存通常放在工作区根的 `.infinity/`；共享卷覆盖写还会在目标同目录创建短期隐藏暂存，提交或失败后清理。其中 `.infinity/` 的 `.gitignore`（内容为 `*`）只在创建时写一次，之后你修改或让 Git 跟踪都不会被改回。新画布镜像与未指定路径的媒体默认落在主工作区；会话专用空间作主工作区或会话添加了外部文件夹时落在会话专用空间。长按条目进入多选，可复制、移动、重命名、新建文件夹和删除：改名与移动在原处完成、不受大小限制，复制同名时自动命名为“名称 (2)”；删除先备份到回收站（保留 7 天、总量 32 MB），可在“回收站”页恢复，超出容量的条目会询问是否永久删除。Agent 删除的文件进入同一个回收站。生成进行中或有待审批时文件操作会被拒绝。目录工作区下暂不提供搜索与导入。工作区不可用时文件区只显示原因与重试，不会改为显示会话专用空间。

推拉私有仓库：HTTPS 远端在“设置 → 执行环境与连接 → Git 凭据”中按主机保存用户名与访问令牌（GitHub 建议使用对 Contents 有读写权限的细粒度令牌），之后 `git clone/pull/push https://主机/...` 自动带认证，无需把令牌写进 URL。内置模式与 Linux 模式的 HTTPS Git 推拉共用这些凭据：应用为每条命令经本机代理注入认证，不把令牌写入工作区或 Linux 的 Git 配置；远端请使用 `https://主机/仓库路径` 形式，主机与设置中保存的一致。`git@主机:路径` 与 `ssh://` 远端使用“SSH 主机与终端”中的主机：例如添加主机 `github.com`、端口 22、用户 `git`，选择私钥认证并把公钥加到代码托管平台，验证并固定主机指纹后即可使用。推送仍按 `shell_exec` 的审批规则确认。

点会话标题下方状态行中的工作区打开“Agent 可达范围”，汇总本会话 Agent 此刻能碰到的范围：当前工作区的类型与保护（回收站和版本、备份、Termux 可见性、卸载后是否保留），`/`、`$INFINITY_WORKSPACE`、`/skills`、`/mnt/<别名>` 在不同执行方中的含义，文件工具、内置命令、隔离脚本、Termux、SSH 五类执行方的可用状态，当前权限范围（工作区或完全访问），以及各工具对公网、局域网、本机、tailnet 的访问范围。面板只展示现状，判定仍在每次工具调用时进行；局域网白名单可在面板内直接编辑。设置 → 工具 → 网络访问提供同一张总表与白名单、Tailscale 入口。

## 外部文件夹使用

从会话资源面板或资料页“浏览”分组打开“外部文件夹”面板，在“添加文件夹”分组选择授权方式，设置别名，再选择文件夹；浏览挂载内容与挂载回收区都在同一面板内逐页进入，返回键逐级退回管理页。系统文件选择器可选择已安装 Termux 提供的主目录；Android 11 及以上禁止选择内部存储根、可靠 SD 卡根、Download 目录及 Android/data、Android/obb。详细边界见 [Android SAF 文档](https://developer.android.com/training/data-storage/shared/documents-files)。侧载版的真实路径入口先打开系统所有文件访问设置，返回后输入共享存储目录；应用私有、系统、Android 子树和符号链接均拒绝。

文件工具可用 `/mnt/<别名>/...` 或列表返回的 UUID 访问挂载。`write_file` 与 `patch_file` 必须提供 `expected_sha256` 或 `expectedHash` 之一（取自 `read_file` 返回的 `sha256` 或 `Hash`），私有工作区与挂载路径相同；缺失时返回 `MISSING_VERSION` 指引，版本冲突会拒绝覆盖。SAF 提供商没有可靠重命名能力时拒绝覆盖已有文件。具备重命名能力的提供商也没有跨应用 CAS 保证，外部编辑器与工具同时修改仍有短暂竞态。支持原子不覆盖移动的真实路径卷先写临时文件，再原子隔离原对象、核对版本并以不覆盖方式发布；原名可能短暂缺失。共享存储卷明确不支持该移动原语时，覆盖写会先将完整内容写入目标同目录的隐藏暂存并同步，核对原文件身份和版本后原子替换，目标不会显示半截内容；新文件也优先在核对目标名未占用后原子发布。移动在核对源身份及目标名空缺后执行普通重命名，明确跨卷时使用快照复制、校验与删除（上限 32 MiB、1000 个条目、32 层深度），删除则逐项核对后删除；最终核对与系统调用之间仍有短暂竞态，与其它应用同时操作时不保证严格 CAS。普通发布也不可用、需要独占创建复制的新文件可能短暂显示未完成内容。其它应用持有已打开的写句柄时，最终版本核对后也有竞态。恢复遇到并发占用或目录无法安全自动还原时，保留隔离副本并返回 `RECOVERY_REQUIRED` 和位置，需人工核查。

共享存储在读取文件时可能刷新时间属性。文件工具会用独立完整读取的摘要复核这类变化，身份、大小或可观察的内容变化仍返回 `CONFLICT`，错误写明不一致的字段。跨卷复制移动在创建目标时记录对象身份；失败后补回缺失的来源条目，再删除身份和内容仍匹配的自有目标。来源已删除且目标完整时按移动完成处理。遇到并发替换、修改或无法完成补偿时，返回 `RECOVERY_REQUIRED` 并列出来源与目标两条路径，保留相关数据供核查。该补偿在进程存活时执行，不提供崩溃后的事务恢复。

若进程在隔离后、发布或恢复前退出，原名可能持续缺失，当前没有启动时自动恢复。请在挂载根用支持显示隐藏文件的文件管理器核查 `.infinity/` 中的副本（各目录中的 `.nexara-replace-*`、`.nexara-delete-*` 及对应 `.infinity-*` 副本在访问到该目录时迁入 `.infinity/legacy/`），确认内容后移回未被占用的名称；保留并发出现的同名文件，避免覆盖。普通挂载列表隐藏这些内部副本。

挂载删除副本保存在应用私有回收区，内容总额上限 32 MiB、最多 100 项、保留 7 天，可从外部文件夹管理页恢复。副本不足时默认拒绝删除；显式 `irreversible=true` 必须逐次 DELETE 审批，审批卡注明“不可恢复”。资料使用独立快照，源文件修改后可重新导入，不自动实时同步。挂载配置和 URI 授权属于本机状态，不进入跨设备备份。

`/mnt` 是虚拟保留名。升级前已有的私有 `mnt` 目录保留原文件与 UUID，不自动搬移或覆盖；可在原文件面板将其重命名后通过普通路径访问，其后代仍可通过原 UUID 操作。挂载管理的重新授权要求选择同一来源，避免既有审批路径指向其它文件夹。
