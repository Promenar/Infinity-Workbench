# 功能详解

> 所属：[使用指南](README.md)。仓库首页只介绍概览，本文给出完整说明与边界。

模型管理支持独立公共目录更新（界面称“规格库”，在模型管理页右上角菜单手动更新；“同步”只指从服务商拉取模型列表）：GitHub Actions 聚合来源并签名发布，App 验签缓存并保留用户编辑。使用与维护方法见[模型目录说明](../model-catalog.md)。

## 能力一览

- **多服务商 BYOK 对话**：支持 OpenAI（Chat Completions 与 Responses）、Anthropic、Google Gemini API、Google Vertex AI、DeepSeek、GLM、Kimi 及 OpenAI-compatible 接口，包含 SSE 流式响应、多模态输入、Markdown/LaTeX/Mermaid/ECharts 渲染和会话内模型切换。表格按单元格内容计算列宽（56–280dp，超出换行），总宽超过屏幕时横向滚动，单元格内保留粗体、斜体、行内代码与链接。
- **启动自检不锁死应用**：启动恢复某一步失败时只隔离受影响的工作区、会话或子系统，其余照常使用；隔离范围只读，可在问题面板重试、确认后放弃未完成的操作、导出脱敏诊断或让 Agent 诊断。只有数据库或备份恢复本身不可信时才阻断进入，阻断页同样可导出诊断。
- **历史 Provider 安全恢复**：无法识别的历史主/额外 Provider 会在管理页显式显示且保持零联网；用户可保留名称与地址进入修复流程，明确选择新协议并处理凭证后恢复使用。
- **完整文档上下文与会话分支**：输入栏可把 TXT/Markdown 全文作为当前消息上下文发送，超出最终路由模型预算时在网络请求前阻止；会话可导出为可回传的 Markdown/TXT，也可导出为网页（HTML）、A4 分页 PDF 或长图 PNG（导出面板可选是否含思考、工具调用与附件，`/export` 可带格式参数），并可从稳定消息创建独立分支。从其他应用分享进来的文件不限格式，可导入当前或其他会话、Linux 环境任意目录或资料库文件夹；应用不能解析的格式原样保存，Linux 会话的智能体可用 `copy_knowledge_to_linux` 把资料库文件复制进 Linux 用命令处理。
- **设置界面**：设置页共用 48dp/64dp 设置行，窄屏长标题与放大字号可自然增高；首页导航不显示脚注，详情页说明使用阅读换行。同组图标统一有或无，数值由“当前值 + 箭头”进入底部选择弹层，少量整数用行内步进器。当前条件下不生效的设置与操作保持可见但灰显，下方写明原因（例如内置提供商不可删除、未安装 Linux 环境时的 Linux 选项）。会话设置依次为模型、参数、工具、上下文；范围、默认值和偏好键见各设置说明。折叠屏内屏与平板（去掉导航栏后宽 ≥ 700dp、高 ≥ 480dp）设置页分两列：左列目录、右列所选设置页及其下层页面，终端、文件等整页内容仍全屏打开，开合屏保持所在页面。设置首页按模型、智能体运行（执行轮次与预算、内置工具、技能包、MCP 服务器）、知识库（知识库设置、知识图谱、长期记忆、调试与高级）、执行环境与连接、数据分组；版本号与渠道显示在“关于”行副标题，关于面板可复制版本信息，页尾是居中的 GitHub 标志；提供商与模型页列表行显示连接状态与能力图标，模型编辑为整页。
- **折叠屏首页三列**：折叠屏内屏与平板（去掉导航栏后宽 ≥ 700dp、高 ≥ 480dp）的「对话」页签分为功能导航、会话助手列表与会话三列，点会话在右列打开，右列没有会话时显示“新对话”入口。会话左上角的“←|”把整排左移：导航推出屏幕、列表收成带状态徽标（生成中、待批准、待回答、排队中）的图标条，会话扩为带检视器的宽会话；“|→”或系统返回还原三列，图标条顶部按钮可展开窄列表。开合屏时右列会话与整页会话互相迁移，外屏行为不变。
- **会话阅读与输入**：单行顶栏（窄窗口右侧只有选项菜单，产物、浏览器与文件是菜单首组；标题下方状态行依次是运行模式、工作区与 Git，宽度不够时先收起分支名，再把 Git 与运行模式收成图标；点工作区打开“Agent 可达范围”并可切换工作区）、右侧用户气泡与通栏助手正文；思考、工具、检索以自然语言步骤行呈现，详情按需展开。完成回复下方提供操作行和模型时间，复制包含整轮正文；点击模型时间弹出该回复的生成统计（输入/输出 Token、缓存读取、推理 Token、首 Token 耗时、生成速度、端到端耗时与运行时间分布，多轮工具调用按整条回复合计）。思考详情支持 Markdown，审批卡顶部是类别条（内置工具或哪类命令、执行位置、风险标签），标题写“需要批准：动作”并附确切工具 ID，其下是命令或参数预览、类别说明与后台运行方式，“拒绝 / 批准”等宽并排；多项审批各带类别条列出后续调用。子代理需要授权时，当前打开的会话在会话流底部按子代理分组显示同款审批卡（“拒绝 / 允许”），运行坞的待批准计数包含这些请求；其它会话的子代理审批仍以全局弹窗提醒。流式挂载显示已有内容，新文字按到达速率逐帧放出，生成结束后自动跟随尾部布局；生成中往回翻看会暂停跟随，推到底或滑回尾部松手即恢复；输入框、附件、执行模式、模型选择、上下文用量和发送/停止共用一个与底部导航同款厚实质感的浮岛；“+”右侧的盾牌按钮切换执行模式（工作区 / 完全访问，完全访问时换成琥珀色警示盾牌），仅在开启工具时显示。浮岛顶部是一行运行坞：显示当前步骤或运行状态、计划进度与用时，右侧依次是待批准跳转、后台任务、状态面板入口与生成中的触摸锁，与输入区之间是一排随状态流动的小灯，计划进度由文字中的“2/5”表达；点开进入运行详情（顶部状态卡写清状态、大号用时与“计划步数 · 后台任务运行中 / 已结束”；计划、后台、状态三页按页签顺序横向切换，计划按顶层分组、完成的组折叠，底部是“标记完成 / 继续处理”，后台任务按运行中 / 已结束分组，运行中带实时输出与停止），隐藏计划后状态胶囊位于浮岛上方。折叠屏内屏或平板（宽度 ≥ 600dp、高度 ≥ 480dp）时，运行信息、资源管理器、Git 变更与本会话产物收进会话右侧的浮动检视器（任务、文件、Git、产物四个页签与加宽、收起按钮都在检视器底栏，收起后是贴在右下的带角标边缘条，没有内容时隐藏），浮岛不再显示运行坞；会话让位后不足 480dp 时检视器浮在会话之上、不挡输入区，上滑面板在宽窗口改为居中对话框，模型速选、本轮记忆、运行模式与执行模式以及设置页的主题模式、语言、协议类型等短单选改为贴着触发控件弹出的浮层。生成中输入行右侧的点阵波形屏显示读数与速率柱，结束时随浮岛光效与运行坞一起收起（设置 → 外观 → 生成动效 可换成绕行流光、潮汐呼吸、网孔背光、底沿数据流或扫光点阵）；浮岛材质可选环境光（默认，光效裁剪在浮岛内部、从点阵屏一侧漫开）或毛玻璃（半透明表面实时模糊背后的会话内容）；出错时整圈泛红后消退；生成期间可以继续写下一条（含图片与文档附件），发送即进入当前会话的排队托盘，本轮成功结束后按顺序自动发出；排队消息可编辑、删除、移到最前或“插队”——当前轮在下一次工具调用结束时提前收尾、保留已完成的工具结果，随后立即发出该条。本轮失败、被停止、应用重启或结束时不在该会话，队列暂停并说明原因，点“继续”恢复。行首输入 `/` 弹出命令候选：`/技能名 补充说明` 让模型在这一轮直接按该技能工作（客户端预先加载技能说明），内置命令 `/new`、`/rename`、`/prompt`、`/compact`、`/clear`、`/mode`、`/tools`、`/export` 直达需要多步操作的会话动作，其中 `/export` 可把会话导出为 Markdown 或纯文本。助手正文长按即可自由选择文字，用户气泡的长按菜单提供“选择文本”；选字工具条中的“引用”把选中文字作为引用卡放进输入区，可逐段写批注后随消息发送（发给模型为“> 引文”加批注），用户气泡上方显示引用，点引文跳回来源那一轮；会话、消息、文件与画布卡片的长按菜单从手指按住的位置弹出，全站菜单统一为圆角浮层、按压高亮与分组的删除项；点浮岛上的上下文用量圆环，贴着圆环弹出用量面板（带自动压缩阈值刻度的环形总览、系统指令 / 历史摘要 / 对话 / 知识增强构成条与“立即压缩”）；回复生成期间屏幕始终保持常亮。生成中点运行坞的锁（宽屏在右侧检视器底栏或边缘条）进入触摸锁：全屏黑色界面只显示运行状态、当前步骤与进度，任务照常执行，返回键与其它触摸都被屏蔽，适合把手机暂时放进口袋；解锁方式在 设置 → 外观 → 触摸锁解锁方式 中选择“长按锁 1.5 秒”（默认）或“把锁拖到轨道尽头”，生成结束后锁保持到手动解锁。回复下方不再显示轮次与调用统计，生成统计从模型时间进入。AI 可以创建会话画布（可视化展示、交互小工具或临时工作台），生成中以紧凑卡紧跟在创建它的步骤下方，回合结束后在正文下方汇总为“本轮产物”（缩略图按手机宽度排版后缩小），窄窗口由顶栏选项菜单第一项“产物”（有产物时带数量）打开与文件、浏览器同样的整页列表（宽窗口在检视器“产物”页签），全屏查看可切换历史版本、复制源码，页面还能把文字写进输入框草稿供你发送；画布不能联网，页面脚本需要 Google WebView 152 及以上，否则只显示静态预览。暗色主题下没有自带暗色适配的画布页面由系统自动变暗（Android 13 起）。产物页按原型、页面、文档、图片、其它分类筛选；AI 可以做多屏可点击原型，打开后先在画板上平铺所有屏幕（可缩放拖动），再进入演示模式点着链接逐屏走；AI 交付的报告、文档、图片等文件登记为产物后保存私有快照（单文件 25 MiB、每会话 256 MiB、保留最近 5 版），本轮改动但未登记的文件出现在产物页“可能的产物”区，可收为产物或忽略。文字游戏或写作时，AI 可以建立会话状态面板（文本、数字、进度条、列表字段），每轮自动更新，运行坞的状态入口点开即可查看（数值与进度两两并排，刚更新与你改过的项带标记）并手动修改，状态随重新生成、删除消息与分支一起回退或复制。空会话中央以灯珠拼出 INFINITY 字标，光带扫过后飞散成 ∞ 形莫比乌斯灯珠环再聚回，点按切换形态、环阶段可拖动转视角，有消息后不再运行（生成动效 中可换成粒子字标、灯珠字标、粒子流环、灯珠环、字标变形或灯珠星球）；生成状态指示在整轮生成期间持续显示，默认运算矩阵，可选波浪跳跃与其余交换机指示灯风格；浮岛光效与生成状态指示按首字前、流式输出、工具执行、等待审批、重试等待五个阶段切换节奏与颜色，流式时跟随实际出字速率，等待审批时浮岛保持第三色慢闪；强调色除 10 个预设外可用色盘自定义，并可选柔和、鲜艳、忠实、表现力四种配色风格；系统关闭动画时以上效果均为静态。断网、超时或限流时自动重发本轮请求（默认 10 次，工具设置中可调 0–20），等待期间显示原因、倒计时与次数。发送后输入框与附件立即清空，生成被回滚时填回。OpenAI Chat Completions 兼容协议族按来源字段回传思考内容（满足 DeepSeek、Kimi 带工具调用时的官方要求），Anthropic 协议在工具循环内回传带签名的思考块，签名被拒时去掉思考块重发一次；Gemini API 与 Vertex AI 回传 thought signature 并支持工具调用。视觉合同和验证边界见 [design-qa.md](../../design-qa.md)。
- **会话请求头**：提供商编辑页可开启“会话请求头”（默认关闭）并填写请求头名称（默认 `x-opencode-session`，如经 NEWAPI 中转 OpenCode Go 时使用），模型编辑页可设为跟随提供商、开启或关闭，模型设置优先。开启后与某个对话绑定的请求（多轮对话、工具续请求与重试、标题、压缩与摘要、子代理、会话记忆与图谱）同时发送该请求头与 `User-Agent: Infinity-Workbench/<版本>`；请求头的值是由本机随机盐与会话 ID 计算的匿名标识，同一对话稳定、不同对话（含分支与子代理）互不相同，不含密钥或对话内容。连接测试、模型目录、嵌入、重排、文档索引等不属于某个对话的请求不发送。是否发送只看设置，不按接口地址自动判断；设置随备份迁移，匿名盐不备份，重装后标识会变化。
- **会话上下文管理**：未达阈值时发送全部未摘要历史；达到阈值后先折叠较早工具结果，再将最近 N 轮之前的对话总结。会话设置可调整阈值与保留轮数，用量面板和设置均提供“立即压缩”；压缩使用当前会话模型，完整记录保留。规则与兼容说明见[上下文管理](../context-management.md)。
- **会话媒体与实机诊断**：生图、MCP、下载与脚本产出的图片、视频、音频统一保存在默认落点的 `media/<日期>/`（主工作区或会话专用空间，规则见[工作区 · 自选工作区使用](workspaces.md#自选工作区使用)），模型以 `![说明](工作区路径)` 引用后在会话内显示为图片、视频、音频或文件卡片，视频与音频可内联或全屏播放，可保存到相册或下载目录、分享；支持多模态的模型可用 `view_media` 查看工作区媒体，只支持图片时视频按可调密度抽关键帧；设置页可导出有界、脱敏的 JSONL 诊断事件，辅助定位真机上的 Provider、生成和会话删除问题。
- **RAG 与知识图谱**：导入 TXT、Markdown、PDF、Word、HTML 文档，提供向量检索、FTS5、Rerank、查询重写、引用追踪、持久知识图谱聊天检索和有界图谱浏览；图谱页分全局、文档、会话三个视角，会话视角可按轮查看每轮抽出的实体，点实体查看来源文档与会话轮次。检索高级设置可调整图谱扩展、即时抽取回退及文档抽取预算；大文档建图需确认，超预算展示部分完成进度。对话记忆按时间线注入：每条记录带所属消息的时间、按先后排列，回顾某段时间的问题（如“上周二我们聊了什么”）按时段检索；设置 → 知识库 → 知识库设置 的“每轮抽取”中可开启“提取事件与状态”（默认关闭，每轮多一次模型调用），同一“对象 · 属性”以最新值为准随检索提供。记忆与文档检索需要在 设置 → 默认模型 中选择嵌入模型；未选择时检索静默跳过，会话页只提示一次。生图、嵌入、Rerank 与查询改写都按所选模型所属的提供商发请求（地址、凭据与远端模型名取自同一提供商），所选模型或提供商被删除、禁用或缺少凭据时直接报错，不改用主提供商；Rerank 需单独选择重排模型，未选择或请求失败时保留原召回顺序。生图与 Rerank 只支持 OpenAI 兼容协议的提供商。设置 → 默认模型 → 等待响应超时 分别设置对话、图像、嵌入与重排模型多久收不到任何数据才判定超时（默认 120 / 120 / 30 / 30 秒，范围 5–1800 秒），改动后下一次请求生效；持续输出的长回复不受总时长限制。长期记忆是另一套用户级记忆：助手认为值得跨会话记住的偏好、协作反馈、项目事实与资源位置会主动写入（无需审批，会话里显示“已记住”并可撤销），所有非私密助手每轮都能看到；在 设置 → 知识库 → 长期记忆 中查看、编辑、删除或关闭。私密助手不读写长期记忆，删除会话或重新生成也不会删掉已写入的记忆。检索深度、分块、阈值等检索参数只在全局知识库设置中调整；会话只控制记忆、文档、重排序与图谱开关及检索范围，全局开关是新会话默认，智能体只保留检索范围上限与新会话默认。
- **Agent 与工具调用**：内置联网搜索、计算、隔离脚本、工作区文件（读写、补丁、新建、移动、回收、内容搜索）、图像生成和任务规划等工具，按“工作区 / 完全访问”两档范围授权并提供写入预览、幂等执行账本和可纠错的工具结果回传。工具设置默认 50 轮，可选 1–100 轮或“不限”；不限模式同时取消固定调用数限制，配有 token 预算、重复调用暂停、上下文压缩和私有大输出分页读取。首次“不限＋完全访问”执行需确认，聊天页与前台通知显示进度且可停止；预算耗尽后自动总结。技能分两级：用户级位于 `/skills`、所有会话共享，目录型工作区的 `.agents/skills/` 为项目级技能（需用户信任）；Agent 可用文件工具或 shell（`$INFINITY_SKILLS`）查看、新建、修改技能或 clone 技能仓库，写入技能目录逐次审批。模型在任务匹配或用户以 `$技能名` 点名时按需加载技能指令、参考文件并运行附带脚本；用户级技能随备份迁移。任务计划以融入输入框顶部的单行计划条呈现（当前步骤、进度与进度线），点击向上展开步骤列表与“标记已完成 / 继续处理”，出现、收起与展开均带尺寸动画；计划全部完成后停留片刻自动收起；× 隐藏未完成计划（收为状态胶囊，计划推进后自动重新出现）或清除已完成计划。生成停止后仍可人工继续或销项，不会把残留计划误报为仍在生成。
- **智能体头像**：头像有符号、生成与照片三种样式。符号取自 390 个 Material Symbols Rounded，按分类浏览或用中英文搜索；生成头像是按智能体 ID 决定的渐变首字母，可换一批；照片沿用裁剪流程。12 种色调自动适配浅色与深色主题。智能体编辑页点主图或“头像”行打开选择器，按“完成”保存。新建智能体默认使用生成头像；仍为出厂样式的预置智能体升级后自动换成新头像。
- **智能体知识检索**：智能体编辑页的“检索方式”决定检索如何发生：每轮自动（发送前检索并注入）、仅工具（模型按需调用 `knowledge_search`，每轮最多 6 次）或两者；会话关闭工具或模型不支持工具调用时回到每轮自动。“知识库文件访问”为关闭、按需申请或始终：按需申请时模型调用 `request_knowledge_access`，会话出现访问授权审批卡，批准后知识库以只读方式挂载到 `/mnt/<别名>`，只能用文件工具读取，命令不可达；“始终”在新会话首次创建且工具开启时直接挂载，移除后不会被补回。外部文件夹面板也可手动“挂载知识库”。检索详情为每条结果标注引用编号、相似度与重排分，以及可读取的路径。
- **联网搜索提供商**：设置 → 工具 → 联网搜索中可选择 DuckDuckGo、Keenable、Tavily 或 SearXNG；模型只看到一个 `web_search` 工具（参数只有 query），工具调用与会话联网检索共用该选择。Keenable 无需密钥即可使用公共共享额度，可选 API Key 使用账户额度；密钥由安全存储管理，仅在用户选择包含密钥的加密备份中导出。搜索结果保留网页来源、链接与摘要。
- **多会话并发与提问卡**：最多 4 个会话同时生成，其余按发送先后排队，会话列表标出生成中、排队中、待批准与待回答；停止或删除只影响该会话，多个会话后台生成时合并为一条前台通知。本地模型的所有调用共用一把推理锁。AI 需要你做决定时可用 `ask_user` 一次提出若干单选、多选或自由回答的问题，会话中以提问卡呈现（单选自动下一题，可跳过，也可在输入栏写其他回答）；等待回答时本轮暂停、释放并发名额并在后台通知，回答后在原轮次继续，已答内容保留为“你的回答”摘要。子代理不能提问。
- **后台子代理**：AI 用 `agent_task` 派出的子代理默认在后台运行，本轮立即拿到子代理 ID 继续工作，子代理完成后结论自动交回：会话空闲时发起新一轮，生成中在当前步骤后插入，等你回答或批准时暂缓；同一结论只交回一次，应用重启后补送。全应用最多 6 个子代理同时运行，其余排队，与会话的 4 个生成名额互不占用。AI 也可以等待结果（`background=false` 或 `agent_wait`），等待时卡片显示剩余时间与“转入后台”，点一下主会话立即带着当前进度继续。AI 可以用 `session_read` 查看进度、`session_send` 追加指令或要求收尾（`wrapUp` 后最多再走两步给出结论）、`session_stop` 停止；你也可以在卡片或查看页停止单个子代理。子代理默认跟随会话模型；智能体设置的“子代理”一节可固定另一个模型，或允许智能体从勾选的模型中按任务指定，指定模型不可用时直接报错、不改用其它模型。子代理沿用主会话的执行模式（完全访问时同样免审批，强制审批的操作除外），AI 可以按任务限定可用工具。查看页列出任务、工具档位、模型、轮数上限、用量与过程，主会话的追加指令、转入后台与停止也记在过程里；结论过长时全文写入工作区 `subagent-results/`，结论里给出路径。子代理用量计入用量统计的“子代理”分类。
- **分支会话**：AI 判断某项工作适合独立进行时，用 `session_branch` 提交工作方案，会话底部出现方案卡：目标、步骤与三项可轻点切换的选择（工作方式：共用主会话工作区或新建 git worktree；上下文：全新或继承主会话摘要与最近消息；审批模式：默认沿用主会话）。你可以“派发到分支”、“在此执行”（主会话按同一方案自己做）或“不需要”。分支是独立的普通会话，与其它会话共用 4 个生成名额，在首页排在主会话下方并带分支标记，会话开头的方案入口与顶栏分支图标可回到主会话。主会话、分支与子代理之间用 `session_send` 互发消息，收到的消息显示来源并可一键打开对方；空闲时收到消息会自动开始新一轮，连续 8 次无你参与的自动处理后暂停，等你回来继续。`session_list` 列出同一家族的会话；读取同助手的其它会话需要你逐次批准。Git 页“分支”页签列出仓库全部 worktree 与在用的会话；删除绑定了 worktree 的分支时可勾选一并移除（不强制，有未提交改动时 Git 会拒绝并保留）。
- **Agent 浏览器**：Agent 用 `browser_open`、`browser_snapshot`、`browser_click`、`browser_type` 在应用内的系统 WebView 中打开网页、读取可操作元素（带 `e12` 这类编号）与正文、点击和填写文本框，适合需要交互或登录才能看到内容的网站。浏览器使用独立配置文件，Cookie 与登录状态和其它应用隔离、跨会话保留；目标地址与 `web_fetch` 共用网络访问判定。手机会话的“浏览器”在顶栏选项菜单首组（Agent 使用中或需要你处理时菜单按钮挂状态点），宽屏改为检视器侧栏常驻的“浏览器”页签（侧栏收起时边缘条显示状态点），可随时旁观；地址栏可直接输入网址或搜索词（不是网址时用 Google 搜索，缺协议的域名补 https，只打开 http/https），Agent 还没打开网页时也能自己先打开，旁边是后退、前进与刷新；“接手”、自己点导航或从地址栏前往后 Agent 暂停，“交回 Agent”后继续。密码、支付卡与验证码字段只能由你填写：Agent 遇到时浏览器标出该字段并提示“需要你登录”，你填好点“完成，交回 Agent”，Agent 看不到填写内容。四个工具在 设置 → 工具设置 → 内置工具 的“联网”分组中开关。需要支持多配置文件的 WebView，版本过低时提示更新。
- **SSH 与远端终端**：设置 → 工具 → SSH 主机与终端中管理主机别名、密码或密钥认证，支持生成 Ed25519、导入口令保护的 OpenSSH 私钥和复制公钥。首次连接需要确认 SHA256 指纹，指纹变化会拦截；Agent 可通过别名执行命令、读写 SFTP 和使用常驻 PTY，工作区档下每条命令逐次审批，并支持大输出分页。用户终端支持 ANSI、滚动历史、控制键与旋转调整窗口，本地转发仅监听 `127.0.0.1`。用户终端一直保持连接，直到手动断开、从最近任务划掉应用或应用退出，可选“空闲自动断开”；添加主机时可从内置 Tailscale 的 tailnet 设备中选择。“允许 Agent 管理 SSH 主机”（默认开启，可在同一页关闭，不随备份迁移）开启时，Agent 可列出、新增、修改、删除主机，并为密码主机安装本机生成的 Ed25519 公钥实现免密登录；这些变更在两档权限范围下都逐次审批，密码与指纹只在应用弹窗中由用户输入和确认，工具结果不含凭据。
- **Termux 本机终端**：两个发行渠道均可从设置 → 工具 → Termux 接入与诊断启用集成。`termux_exec` 在 Termux 的 bash 中后台执行，支持工作目录、stdin 和 1–600 秒超时，默认 60 秒；沿用 PROCESS 审批，目标绑定 `termux` 与完整命令。诊断页提供安装、外部调用开关、系统权限、SSH 公钥复制和主目录 SAF 挂载引导。
- **内置命令执行**（内置模式会话）：无需 Termux，`shell_exec` 用系统 `/system/bin/sh`（POSIX sh 与系统 toybox，命令随设备不同）、`python_exec` 用随 APK 打包的 Python 3.14（仅 arm64-v8a，标准库完整，附带 dulwich）直接在会话工作区根目录运行；shell 中可用 `python3`/`python`，以及基于 dulwich 的 `git`（clone、commit、log、diff、push、pull 等常用子命令，远端只支持 HTTPS，不支持的子命令返回 `GIT_UNSUPPORTED`）；侧载版另有 `pip`，可把纯 Python 包装到应用用户目录（含原生扩展的包无法导入），Play 版不提供 pip。`.git` 内部文件入索引但不进入资料向量化。工作区档逐条审批，完全访问档不审批；审批卡以“内置命令”类别条写明命令以 Infinity Workbench 身份运行、可访问全部应用数据、不受工作区限制，删除或覆盖的文件不进回收站。命令结束后检测数据库、`shared_prefs`、`no_backup`、用户级技能目录与诊断日志的变化，在工具行下方常驻标出；系统提示词要求模型改动这些关键数据前取得你的书面同意。运行期间独占工作区写锁（文件工具的读写排队等待），结束后按磁盘对账索引并在 `workspace_changes` 中列出新增、修改、删除与移动；保留路径、符号链接与特殊文件不入索引并给出警告。默认 60 秒、最多 600 秒，超时、取消或命令结束时结束整个进程组，stdout/stderr 各保留尾部 32,000 字符。运行期间持有唤醒锁，侧载版在通知栏显示命令并可停止（Play 版只有唤醒锁）；系统冻结的时间不计入超时，ColorOS 等系统需把 Infinity Workbench 设为“完全允许后台行为”，离开应用后命令才能持续运行。
- **内置 Linux 环境（侧载版）**：设置 → 工具 → 本机与远端 → Linux 环境，一键安装随 APK 打包的 Alpine Linux（proot，仅 arm64-v8a，无需 Termux 或 root）。开启“命令在 Linux 中运行”后，`shell_exec` 与 shell 后台任务在 Alpine 中执行，可用 `apk add` 安装软件包；另有本地终端、Linux 文件浏览、软件包与镜像源管理、命令完整输出查看，`/root`、`/home`、`/opt`、`/srv` 及其子目录可在工作区选择器中逐级浏览并选为会话工作区（系统目录与运行时绑定点不可选），`/root` 同时出现在系统“文件”应用中。交互式命令（如 `gh auth login`）运行在伪终端中，终端会答复光标位置与颜色查询，提问可用 `job_input` 逐步作答。使用方式与边界见[执行环境 · 内置 Linux 环境](execution-environments.md#内置-linux-环境)。
- **内置 Tailscale**：设置 → 工具 → Tailscale 启用后，Infinity Workbench 在进程内运行一个 Tailscale 节点（tsnet），不占用系统 VPN，可与其它 VPN 同时使用；支持浏览器登录或 auth key、自建控制服务器（Headscale）、临时节点与设备白名单。SSH 主机、`shell_exec`、`python_exec`（含内置 git）、应用内 HTTPS 请求以及模型提供商（对话、向量化、重排、生图）可直接访问 tailnet IP 与 MagicDNS 名称，其它目标保持原有路径；`web_fetch`、`media_fetch` 与脚本联网访问 tailnet 时固定经内置 Tailscale 代理，未连接时直接失败；Agent 可用只读工具 `tailnet_status` 查看节点与设备。提供商表单按接口地址自动识别“公网 / Tailscale 内网”API 源，并可从 tailnet 设备下拉框选择网关设备填入地址（内网地址需为 https，可在网关设备上用 `tailscale serve` 提供）；发送到内网模型时会等待内置 Tailscale 接入后自动继续，未接入时请求直接失败而不回退直连（内置 Tailscale 关闭时立即提示去开启），模型选择器以公网与 Tailscale 两盏指示灯显示连通状态。节点只在 Infinity Workbench 运行期间在线，退出后下线。
- **本机 MCP（高级）**：工具的 MCP 配置中可显式开启本机 HTTP，仅接受 `http://127.0.0.1:<端口>`。访问令牌必填并由 SecretStore 保存，发现和执行均使用 Bearer，工具按 PROCESS 风险审批；关闭开关立即停止暴露与执行环回工具。
- **会话工作区**：资源管理器与资料页同样按目录下钻浏览（页头只有一个返回按钮，子目录内回到上一级；上级路径可点击跳级，系统返回同样逐级退回），搜索结果平铺并显示所在路径，点击即进入所在目录。按 Session 隔离文件根目录，覆盖导入、原子写入、版本、回收站、恢复和路径逃逸防护；文档索引使用版本化目标与失败重试，进程重启后按当前文件版本和 KG 配置补建缺失任务。
- **后台任务**：`shell_exec`、`python_exec`、`termux_exec` 传 `background: true` 即在后台运行并立即返回任务号，默认最长 2 小时（上限 24 小时），结束后可通知或自动唤醒会话发起下一轮；`job_status`、`job_wait`、`job_stop`、`job_list` 查询、等待和停止。会话专用空间中的任务在副本里运行、结束后合入，冲突保留前台版本并把后台版本放进 `jobs/`。侧载版退出应用后继续运行；Play 版只在应用位于前台时保证运行。聊天页活动标签与面板显示实时输出、停止按钮与日志入口。Linux 会话里的脚本可运行 `infinity-wake [--key K] [--title T] [消息]` 唤醒智能体，会话空闲时发起一轮回复（同一会话 60 秒内最多一次，期间消息按 key 合并）。
- **定时任务**：AI 可在会话中创建单次、间隔或 cron 定时任务（创建总需你批准，审批卡列出接下来三次触发时间），适合 Agent 在长任务中挂轮询（如定期检查构建状态、完成后自行取消）；应用在前台时由应用内计时器准点触发，退到后台时由系统闹钟或 JobScheduler 兜底（可能被系统推迟）。到点在会话里插入“定时”触发行并发起一轮回复，沿用会话的权限范围；需要你处理时暂停并通知，点通知回到会话继续。前台固定间隔最短 1 分钟，重复任务退到后台后精确闹钟间隔至少 5 分钟、系统择时至少 15 分钟；单次提醒用 1–10080 分钟倒计时，你给出具体钟点时才用绝对时间。每会话最多启用 5 个、共 20 个。设置 → 工具 → 后台与定时汇总全部任务和运行条件（精确闹钟、电池优化、通知）。定时任务只存在本机，不进入备份。
- **画布文件**：画布当前版本同时保存为会话工作区的 `canvas/<标题>.html`，可在资源管理器或用文件工具、命令编辑，修改在下次打开或读取画布时成为新版本。
- **工作区三分类**：会话专用空间、内置文件系统与（侧载版）设备文件系统；Agent 可设默认工作区，会话可单独切换，文件工具、`shell_exec`、`python_exec` 与内置 git 直接在该目录工作，资源管理器可复制、移动、重命名、删除与恢复文件，删除会话时可把专用空间文件保留到内置文件系统；会话资源面板为 git 仓库提供只读的变更与提交差异面板，文件工具执行卡与审批卡显示逐文件增删行数与差异。
- **外部文件夹挂载**：文件面板可为当前会话添加 SAF 文件夹或（侧载版）存储路径，以 `/mnt/<别名>/...` 供现有文件工具读写；挂载只属于添加它的会话且一律可读写，支持浏览预览、加入资料快照和恢复删除副本。存储路径挂载另可被命令以真实路径访问，SAF 授权的文件夹只对文件工具可见；系统提示词逐个列出两者。侧载版另提供经过系统“所有文件访问”授权的共享存储真实路径入口，Play 版仅提供 SAF。
- **长文档安全编辑**：严格大于 1 MiB 的文件仅加载元数据；已读取正文严格超过 32K 个 UTF-16 代码单元、2,000 行或单行 16K 个 UTF-16 代码单元时自动进入性能保护，只预览约前 16K 字符，但复制和保存始终使用完整全文。一次输入跨过软线时，已修改内容不会被截断，仍可完整完成 CAS 安全保存。
- **安全备份与恢复**：核心数据可本地或通过 HTTPS WebDAV 手动备份；密钥默认不进入备份。备份包可独立启用加密，包含完整密钥时强制加密；设备本机个人头像与 Agent 头像不跨设备迁移，避免恢复出失效绝对路径。
- **本机头像管理**：个人头像与 Agent 自定义头像共用系统图片选择和 1:1 裁剪流程，可移动、缩放、旋转并明确确认；连续替换图片使用新的内容身份，避免图片缓存继续显示旧头像。Agent 自定义图片与内置向量头像都会提交本地数据库，Agent 首页复用同一持久化头像选择展示。
- **后台持续生成**：前台发起的当前生成任务在切后台、锁屏、旋转或 Activity 重建后继续，通过前台服务通知返回会话或停止任务。回到对话首页时，正在生成的会话在列表中以生成状态指示替换时间（样式随外观设置），会话标题固定单行、过长时跑马灯滚动，等待批准的显示“待批准”；离开再回到会话，思考计时接着走，输入框草稿以离开时为准。
- **本地优先**：会话、文档和配置保存在设备本地；云端模型调用直接连接用户配置的服务商。

## 后台生成边界

后台生成覆盖用户在前台主动发起的单个当前任务：

- 支持切后台、锁屏、旋转和 Activity 重建；
- 通知可返回准确会话或停止生成；
- 通知权限被拒绝时可退化为仅前台生成；
- 不支持设备重启后续传或多会话并行生成；定时任务与后台任务唤醒触发的轮次在应用级全局串行排队，见“定时任务”。
