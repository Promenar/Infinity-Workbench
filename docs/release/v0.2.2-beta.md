Nexara 是 Android 12+ 的 BYOK AI 客户端，提供多服务商流式对话、完整文档上下文、Agent 工具、会话工作区、RAG、知识图谱和手动加密备份。当前版本为本地签名候选，验证及制品身份见[验证账本](v0.2.2-beta-validation.md)。本文件不构成 tag、GitHub Release 或公开资产发布授权。

## 功能与交互

- 知识库集中呈现索引和图谱任务的进度、错误、重试、取消与配置入口，错误状态不会被当成持续索引；文件按当前目录平铺，下钻及面包屑返回复用同层浏览方式。
- 会话工作区与知识库保持身份和索引边界，用户可显式转存文件到知识库；会话文件不会默认进入知识库自动向量化流程。
- 首页、设置、智能体及知识库采用统一操作菜单与导航样式，任务状态保持可见。
- 提示词编辑器支持编辑、预览、行号与滚动，修复 Android 12 上编辑页面可能持续布局的问题。
- 模型目录支持独立签名更新，验签缓存保留用户编辑；维护方式见[模型目录说明](../model-catalog.md)。
- 文件事务身份、备份恢复、双库恢复、完整文档发送及会话分支的行为合同沿用项目实现；每项当前验证范围由账本单独列明。

## 使用边界

- 物理真机 TalkBack 听觉、完整焦点遍历与 OEM/IME 体验需要人工验收，模拟器和静态检查不能替代。
- Release Provider 和 WebDAV 仅允许 HTTPS；用户密钥由设备 SecretStore 管理，默认不纳入备份，包含完整密钥时备份必须加密。
- 个人与 Agent 自定义头像属于设备本机资产，不跨设备备份。
- WebDAV 是手动备份与恢复；后台生成覆盖前台发起的单个当前任务，设备重启续传、多会话并行及无人值守队列不在稳定范围。
- GGUF/llama.cpp 本地推理属于实验性资产，不随 Release 提供稳定能力。
- 历史真实服务结果不证明当前全部 Provider、工具、多模态或检索指标通过；模型或网关失败与未测试的产品指标必须按账本披露。

公开发布需要用户明确授权，账本与说明精确 GO、登记的人工风险接受、同一签名制品的冷安装与覆盖升级证据，并由受保护 workflow 完成构建、设备门禁及资产上传回读。手动 workflow_dispatch 仅验证候选。
