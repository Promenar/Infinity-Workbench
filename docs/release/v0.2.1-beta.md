# Nexara v0.2.1-beta 发行说明

> 发布状态：本地签名 APK 候选，APK 公开发布未授权；独立模型目录已发布到 GitHub Pages
> 发行制品：`Nexara-0.2.1-beta-release.apk`
> 版本身份：`com.promenar.nexara.native` / versionCode `3` / versionName `0.2.1-beta`
> 验证账本：[v0.2.1-beta-validation.md](v0.2.1-beta-validation.md)

`v0.2.1-beta` 是面向现有测试用户的数据兼容修订版。保留已确认的底部三按钮导航与设置视觉语言，修复文件身份、导入、搜索、取消、协议和编辑器状态，并提供来源保全的显式双库恢复。

## 主要变化

- 模型目录从 models.dev、LiteLLM、OpenRouter 和有官方证据的补充条目独立更新，支持签名验证、离线缓存与手动刷新；模型同步保留供应商字段、完整请求 ID 和用户编辑。运行方式见[模型目录说明](../model-catalog.md)。

- Tool Call 使用完整调用身份、持久化账本和确定终态；取消、失败、重放与审批不会静默制造第二次执行。
- MCP Streamable HTTP 支持有界增量 SSE 读取；首个精确匹配请求 ID 的完整响应结束当前请求，畸形、错 ID、截断与超限响应 fail-closed。
- 未知历史 Provider 协议和已退役 Yi 协议禁止联网、探测和凭据投递；未知额外 Provider 在管理列表中以不支持状态显式呈现并允许安全删除。
- 未知协议的主 Provider 同样不再从列表消失，可进入显式修复页；名称、地址与凭证存在状态保留，但必须选择受支持协议并替换或清除凭证后才能保存和联网。
- Generic OpenAI-compatible 模型列表同时接受裸数组与标准 `data` envelope，连接探测和模型同步复用同一解析合同。
- 会话工作区、文件生命周期、回收站、索引任务、分享导入重试和删除恢复使用持久化身份与 journal 收敛。
- RAG 搜索限定当前工作区并使用稳定 BM25 顺序；知识图谱按全局、文档或概念 scope 隔离，切换 scope 不复用其它图谱，失败只保留同 scope 的 last-good 视图。
- 设置、Token、Agent、头像与 Tavily 使用类型化 loading/success/error 状态；头像导入增加大小、格式、尺寸和像素解码限制。个人和 Agent 头像共用可移动、缩放、旋转的 1:1 裁剪页，具备明确“完成”动作和系统栏避让；内容哈希缓存身份保证连续上传立即显示新图片。
- Agent 自定义头像先成功提交本地数据库再更新编辑页，离开页面后不会回退；Agent 首页读取同一持久化头像，并以 88dp 连续 Material 3 列表行、56dp 圆形头像及标准正文层级呈现。既有底部三按钮导航没有改动。
- 从自定义图片切换到内置向量头像时立即写入本地数据库，不再等待页面级文本防抖；首页会按持久化的内置头像显示。已落入会话流的生成失败只保留独立错误气泡，不再在输入框上方重复弹出同文案提示；无法形成消息的前置或持久化失败仍保留顶层反馈。
- 删除用户消息会原子删除同轮助手、工具与错误消息；旧孤立错误使用独立可删除的 Material 3 容器。附件图片删除按钮固定在缩略图右上角，思考框与正文之间不再绘制连接线和点，工具调用链仍保留连接关系。
- 底部三按钮导航的视觉、尺寸与水滴动画保持不变，真实切换时增加系统/OEM 调校的 tick 触感并遵循触感开关；流式正文使用更柔和、更长的尾部淡入，降低逐字符机械闪动。
- 本地和 WebDAV 均明确为手动备份；备份包可独立加密，包含完整密钥时强制加密。Provider 配置跨偏好与 SecretStore 的并发导出使用 revision 门禁。
- 个人头像和 Agent 头像属于设备本机资产，本版不跨设备备份；导出与恢复均清除旧沙箱绝对路径，避免伪成功引用。

## 覆盖升级与数据继承

本版保持正式包名与发行证书，版本为 code 3 / 0.2.1-beta。公开同签名 v0.1-beta 的数据库实际为 v17，v0.2-beta 为 v2；当前库提供前进迁移到 v18。单库升级先验证 Room identity、列合同和 WAL 一致性，再执行迁移。FTS4 完整性检查在一次性私有副本上进行，不对来源库执行验证写入。

曾经过 v0.1→v0.2 的安装会同时保留两库。启动页提供“保留两份并恢复”：分别认证和归档来源，在工作副本上迁移，冲突业务 ID 保留两侧并重映射关联，再发布具有新物理身份的工作区及合法引用资产。两侧 Agent/Session/Message、知识库与旧附件均有实际访问入口；损坏或超预算附件显示不可读取原因。阶段 journal 支持中断恢复，完成切换后的新业务写入不会被重放覆盖，旧工具和索引任务等待用户显式重试。

公开 v0.1→候选与 v0.1→v0.2→候选已使用正式签名包和合成哨兵验证，涵盖 WAL、关联、物理文件哈希、归档、附件点击及安装时间保持。该证据不代表所有真实用户资料已验收。真实设备应保留完整备份，直接同签名覆盖安装，不卸载、不清数据；不同签名、不同包名或来源不明的 APK 不能继承当前安装。

## 安装与校验

维护者直接交付时，应同时提供 APK 路径、字节数、SHA-256、签名证书 SHA-256 和验证账本。校验无误后可侧载；已有同签名旧版时直接覆盖安装。

不要安装 Debug APK、Actions 临时制品或第三方重签名包。本文件不构成 tag 或 GitHub Release 授权；公开发布仍需用户单独批准，并由受保护 workflow 重新完成签名构建、冷安装、覆盖升级和资产回读。

## 已知边界

- 物理真机上的 TalkBack 人工听觉、完整焦点遍历及不同 OEM/IME 体验仍需人工验收；自动化语义与模拟器测试不能替代该结论。
- 个人与 Agent 自定义头像不跨设备备份；同一安装上的覆盖升级会由 Android 保留应用私有文件。
- WebDAV 是手动上传、列出和恢复，不是后台同步或定时备份。
- GGUF/llama.cpp、本地推理、设备重启续传、多会话并行和无人值守任务不属于本版稳定范围。
- Release Provider 与 WebDAV 只允许 HTTPS；无密钥回环网关仅用于显式测试变体。
- 指定网关中 DeepSeek、SenseNova、Luna 的文本与双轮工具通过；Gemini 工具流错误、MiniMax 空响应保留为服务侧失败，不能声称五模型全绿。
- 模拟器性能只覆盖已测场景；全局16ms、TTFT、检索召回率、覆盖率、真实崩溃率与16KiB运行仍按验证账本分账。
