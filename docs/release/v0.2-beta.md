# Nexara v0.2-beta 发行说明

> 发布状态：**PENDING / NO-GO**
> 发行渠道：GitHub Release 可侧载 APK
> 目标 tag：`v0.2-beta`
> 最终放行依据：[v0.2-beta 验证记录](v0.2-beta-validation.md)

本文是 `v0.2-beta` 的发行正文草案。只有验证记录中的全部 P0 门禁完成、tag workflow 全绿并实际上传签名 APK 后，才可把状态改为已发布。

## 版本定位

`v0.2-beta` 是 Nexara 的首个可侧载发行候选：面向 Android 12 及以上设备，提供多服务商 BYOK 对话、RAG/知识图谱、Agent 工具、会话工作区、安全备份与前台服务后台生成。产品数据仍以本地优先为原则，云端模型调用直接连接用户选择的服务商。

## 主要更新

### 后台持续生成

- 前台发起的当前生成任务可在切后台、锁屏、旋转或 Activity 重建后继续。
- 应用级 `GenerationCoordinator` 是唯一任务状态源；UI 与前台服务观察同一任务，不重复请求。
- 通知显示生成状态，并提供返回准确会话和停止生成操作。
- 取消、失败与完成形成明确终态；重复提交不会制造第二次网络调用。

### 多 Provider 与错误恢复

- 模型通过稳定 `providerId` 在每次请求开始时解析到 Provider、协议、Endpoint 和凭据。
- 覆盖 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages、Vertex AI 与 OpenAI-compatible 路由。
- 鉴权、限流、配额、无效请求、服务端、协议、持久化与未知错误使用稳定分类；原始技术异常不会直接成为用户文案。
- 流式通道支持背压，不因下游变慢静默丢弃文本或工具片段；取消不会被误报为普通失败。

### RAG、知识图谱与工作区

- 文档导入、更新、移动、删除与重试进入真实持久化/索引链路。
- 重索引先构建隔离候选，事务内复核源文件哈希后原子切换；失败保留旧索引。
- 永久删除统一清理向量、FTS、KG、标签和任务记录，并通过 tombstone 覆盖进程死亡窗口。
- 会话工作区按 Session root 隔离，拒绝路径逃逸、绝对路径和跨会话访问。
- 覆盖安装时仅迁移可精确识别的旧版空哈希工作区根，保留原目录内容；越界、悬空或子路径根继续拒绝。新会话创建、进入与空工作区加载已在 API 35/36 真实应用入口验证。
- 会话目录刷新按数据库同步成员与顺序，同时保留同 ID 会话在内存中的较新流式消息和运行状态，避免迟到快照让已生成内容或按钮状态倒退。
- 系统分享与 SAF 复用持久 importer，逐项呈现导入、拒绝、部分失败和重试状态。

### 密钥、备份与恢复

- API Key 等凭据通过 Android Keystore 支撑的 `SecretStore` 保存。
- UI 默认以 `****` 隐藏 Key；用户可在当前页面临时显示完整值，失焦或离开页面后重新隐藏。
- 备份默认排除所有 Key；用户可显式选择把可备份的完整密钥加入包中，此时必须设置备份密码。
- 含密钥备份使用 PBKDF2-HMAC-SHA256 与 AES-256-GCM；恢复先完成解密、校验和解析，再执行事务写入。
- 支持本地备份和 HTTPS WebDAV；错误密码、损坏包或完整性失败不得产生部分恢复。

### UI、提示词与可访问状态

- 首次引导首条回复完成后继续停留当前聊天，返回键回到主界面；知识库、全局记忆设置和检索设置不再因缺失或越界工作区路径闪退。
- 主界面助手条目改为连续 Material 3 `ListItem`：移除逐项 Glass 描边卡片与冗余进入箭头，采用 tonal 图标、标准排版和正文起始位分隔线；整行进入会话，置顶与更多操作保留独立可访问语义，高密度设备的短滑不再误触删除。
- 设置首页和 Provider 管理使用连续、无逐项卡片的 Material 3 列表与单层分隔线；常规、2.0x 字体和横屏空态使用自适应间距。聊天输入胶囊及模型管理的批量按钮、类型/能力标签和上下文字段按紧凑视觉与独立 48dp 触控目标重新对齐；模型列表展示真实远端模型 ID，内置规格解析优先具体模型并保护用户自定义元数据。
- 统一提示词编辑器的保存/关闭、未保存退出保护、长文本滚动、空预览和 CJK/拉丁统计。
- RAG 移动、索引失败、重试和生成失败状态使用真实动作与结构化提示，不再保留无效 affordance。
- 文档编辑器迁移到标准 Material 3 顶栏、模式选择、单层内容表面、状态提示和对话框；360dp、2.0x、精确 800×360、平板 Split 与真实横屏 IME 保持编辑、保存和恢复入口可达。长代码及引用/列表内宽表格可横向访问，代码块工具栏使用 48dp 目标和双语 TalkBack 描述。
- 关键操作补充最小触控目标、语义角色、稳定输入名称、选中/加载状态和动态播报入口；文档冲突状态在大字体下优先保证复制与重载动作完整可达。
- 简体中文与英文是本版正式语言；62 张截图、Agent 首页 API 36 聚焦交互 6/6、DocEditor API 31/35/36 各 31/31、双 API 新会话入口与 IME 专项已通过。TalkBack 自动语义门禁已通过；当前源码的稳定证书签名 R8 候选也已完成 API 35/36 冷安装，可交由用户真机执行人工听觉、完整焦点遍历和核心业务体验验收。

### 发行安全与工程门禁

- Release 日志入口受 Debug 编译门禁并由 R8 剥离；禁止业务代码直接输出平台日志或完整堆栈。
- Release 使用可移植环境变量签名配置，开启 R8 和资源收缩。
- APK 验证器检查 ZIP 完整性、包名/版本、单一签名者、证书指纹、50 MiB 大小上限、敏感内容和 SHA-256。
- GitHub Actions 覆盖 JVM、Lint、截图、API 31/35/36 设备作业、签名 APK checksum/zipalign、API 35/36 冷安装和幂等 prerelease 资产发布。

### Metro 开发者 TUI

`scripts/nexara-metro-tui.js` 已补齐中文帮助、标准输入、设备/Tag 选择、TTY/非 TTY 输出、明确退出码和错误容错。它只用于 Debug 构建的脱敏日志观测，不是最终用户 CLI，也不提供 Android 应用的功能对等界面；Release 会关闭 Metro 调试链路。

## 安装前必读

### 系统要求

- Android 12/API 31 或更高版本；
- 云端模型、Embedding、Rerank、搜索或 WebDAV 所需的网络连接；
- 使用后台生成时建议授予通知权限。拒绝通知权限后可继续使用，但生成会退化为仅前台运行。

### 不兼容旧数据

`v0.2-beta` 使用新的数据基线，**不兼容 `v0.1-beta` 用户数据**。请在安装前自行保存仍需保留的旧内容，然后卸载旧版再安装，不要从 `v0.1-beta` 直接覆盖安装。对于本次 `v0.2-beta` 早期候选，当前候选只对可精确识别的旧版空哈希工作区根提供保守迁移；其它旧候选数据仍应先备份再验证。

### 校验与侧载

从 [Promenar/Nexara Releases](https://github.com/Promenar/Nexara/releases) 下载：

- `nexara-v0.2-beta.apk`
- `nexara-v0.2-beta.apk.sha256`

Linux：

```bash
sha256sum -c nexara-v0.2-beta.apk.sha256
```

macOS：

```bash
expected=$(awk '{print $1}' nexara-v0.2-beta.apk.sha256)
actual=$(shasum -a 256 nexara-v0.2-beta.apk | awk '{print $1}')
test "$expected" = "$actual"
```

校验通过后，在 Android 系统中允许下载该文件的应用“安装未知应用”，再打开 APK 完成侧载。只安装 Release 页面中的签名 APK；不要把 Debug、deviceTest 或 Actions 临时制品当作正式版本。

## 已知限制

1. **无旧版数据迁移**：必须卸载 `v0.1-beta` 后安装。
2. **GGUF 不属于稳定能力**：本轮不继续推进 GGUF/llama.cpp 端到端实现，Release 关闭本地推理并拒绝打包相关制品。
3. **后台任务不会跨设备重启恢复**：只覆盖当前前台发起的任务，不支持重启续传、多会话并行、无人值守队列或定时任务。
4. **Release 网络仅 HTTPS**：局域网 HTTP Provider 只可用于显式 Debug/Integration 测试，不属于本版发行入口。
5. **深色主题是唯一正式主题**：本版不承诺完整浅色主题。
