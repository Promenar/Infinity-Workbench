## Android FD 测试归属

Linux 托管 Runner 提供 SecureDirectoryStream，原 JVM 测试因此进入 AndroidSnapshotDirectoryCreator，触发未模拟的 Android Os.open；Mac 缺少该能力，走拒绝分支。五个创建/竞态/回滚场景迁入 AndroidSecureWorkspaceCreationRaceTest，在应用私有目录真实运行，缺少安全目录能力直接失败。本机API35五项5/5通过，`device-platform-split-final.log`，测试APK重新编译通过。其余六个 JVM 场景保留，设备脚本 minimum/full 均执行新增类。根符号链接替换以真实 Android O_NOFOLLOW 的 ErrnoException/ELOOP 精确断言拒绝；外部零写入、节点身份、文件保留及回滚检查保持。清理仅对已确认符号链接 unlink，并以 After 回收专用临时目录，避免清理异常遮盖首因。
